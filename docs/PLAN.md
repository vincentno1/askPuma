## 產品定位與體驗

名稱：**該怎麼攻擊 Puma？**

副標：**請輸入攻擊角度，我們幫你檢查會不會打到自己。**

原則：**名字負責挑釁，互動負責搞笑，原始資料負責讓人服氣。**

這是民間支持 Puma 的詼諧網站，不冒充候選人本人或官方競選團隊。可以明白有立場；每個結論仍由收集到的證據決定。

最新 2026-10-04 決策：首頁沿用已認可 01；結果頁大字、少字、本人原貼文優先，其他補充按開。支援動漫玩梗題，事實與幽默分流。布局依 [RESULT_DESIGN](RESULT_DESIGN.md)，語氣與分流依 [HUMOR_MODE](HUMOR_MODE.md)，多題資料入口依 [ATTACK_RESEARCH](ATTACK_RESEARCH.md)。

核心流程：

1. 首頁輸入質疑，最多500字，並提供少量範例。
2. 拆解為可查的主張：例如針具、供毒、除罪化不能混成同一題。
3. 展示相關原話／轉述，標示日期、前後文、來源類型。
4. 展示官方政策或研究，每張卡能展開段落及打開來源。
5. 呈現一句吐槽，再呈現認真的解釋、限制與引用。
6. 複製結果和來源；有餘裕才做結果分享頁。

視覺：暖白、陶土橘、鮮藍、粗中文、黑色偏移陰影，回答頁原文黃色畫線。先完成大字結論與可展開補充的手機版，再加必要動畫。

文案候選：

- 主按鈕：「檢查這個攻擊角度」
- 比對本地資料：「正在比對原文……」
- 真正呼叫網頁搜尋時：「正在找公開資料……」
- 引文缺脈絡：「攻擊失敗：你漏帶了前後文。」
- 證據不足：「彈藥不足，請勿盲射。」
- 多個概念混在一起：「你一次攻擊了三件事，但它們不是同一件事。」
- 頁尾：「立場公開，來源也公開。」

只使用與實際執行相符的進度文案；不播放虛假的爬取或搜尋過程。不要捏造人物發言或用百分比分數假裝測量真假。
