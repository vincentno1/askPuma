# 搞笑題與動漫旁白

2026-10-04，Asia/Taipei。使用者明確要求支援「為什麼要留爆炸頭？」等搞笑題，並多用日本動漫梗。本文件是設計與提示規格，沒有呼叫 API 或實作。

## 產品語氣

認真題讓原文說話，搞笑題讓旁白放飛。名字帶挑釁，回答要像懂梗的朋友接球：短、有反差、第一眼就懂，不寫長篇動漫分析。笑點可繞著誇張戰鬥設定、主角光環、技能樹、回合制、變身與裝備；不虛構人物發言或真正的個人動機。

## 三種輸入

| 類型 | 示例 | 回答方式 |
|---|---|---|
| 事實／政策 | 他是不是主張取消免費午餐？ | 查原文與證據；一句事實結論，動漫梗只作旁白 |
| 輕鬆玩梗 | 為什麼要留爆炸頭？爆炸頭有加攻擊力嗎？ | 「玩梗模式」可見標籤＋大字原創答案；不硬塞查核卡 |
| 混合／不確定 | 他留爆炸頭是模仿魯夫嗎？他親口說過嗎？ | 前者可給幽默但不能斷言原因；問本人是否說過則走事實查核，找不到就說沒找到，旁白另列 |

不要只靠出現「爆炸頭」就走搞笑路徑。「爆炸頭是不是害得市政很差」含能力主張，仍需拆主張；「收錢」等實質指控也不能因動漫措辭變成無來源笑話。對讀者人身羞辱不會讓笑點更好，吐槽聚焦問題角度與虛構戰鬥場面。

## 第一批原創文案草案

全部是本站創作，**不是 Puma 或動漫人物的逐字台詞**。最多一個主要梗；讓不熟作品的人也能看懂。正式上線從短素材表選梗，模型變化措辭，不憑空編造動漫劇情。

| 訪客題目 | 大字答案草案 | 可選旁白／聯想 |
|---|---|---|
| 為什麼要留爆炸頭？ | **你以為是髮型，其實是戰鬥型態。** | ONE PIECE 爆炸頭魯夫／Afro Power 的聯想；不是本人留髮原因 |
| 這顆頭是不是太大？ | **那是主角光環，已經長出實體。** | 泛少年漫畫設定，原創比喻 |
| 可以叫他剪頭髮嗎？ | **可以，但你確定要先解除裝備？** | RPG 裝備梗；不編造已量測攻擊力 |
| 他頭髮會不會擋住視線？ | **你看的是劉海，他開的是見聞色。** | ONE PIECE 技能名聯想，純旁白 |
| 他怎麼回應那麼長？ | **你才放一句話，他已開始詠唱。** | 泛動漫長詠唱梗；若問實際回應內容，先呈現原文 |
| 我只是想嘴一下，怎麼出現這麼多證據？ | **你開了嘴砲局，他帶了攻略本。** | 適用真的找到來源時；無證據不能假装已帶攻略 |
| 為什麼不能只看截圖？ | **這不是寫輪眼，不能一眼補完前情。** | 火影技能名聯想；認真理由展開時說明截圖缺語境 |
| 有沒有一招打倒他的問題？ | **先別找必殺技，先確認有沒有命中。** | 泛少年漫畫／遊戲梗，不承諾每一題都能護航 |

## ONE PIECE 梗的來源與界線

- 使用者指定「戴上爆炸頭充滿力量」作為聯想方向，不是交付了精確作品引言。
- [官方動畫第 217 話頁](https://one-piece.com/anime/217/index.html) 可確認 Davy Back Fight 的船長對決背景；這頁摘要沒有列爆炸頭加拳力的逐字對白。
- [NetEase 的官方聯名新聞稿](https://prtimes.jp/main/html/rd/p/000000112.000071247.html) 明確提到魯夫在 Davy Back Fight 對戰佛克西時的爆炸頭造型，適合作聯想來源。它不證明髮型有真實物理效果。
- 若要標具體集數／章節、角色說過的台詞或劇情規則，D 先核對原作／官方授權版本；本版採原創改寫，避免不確定的逐字引言。不要把網路梗圖上的字直接算作原作。

提示約束：
